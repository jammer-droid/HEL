# 설정 리뷰

1. 이 skill 디렉터리의 `references/rules.md`를 읽는다.
2. 사용자가 지정한 설정 파일을 읽고 참고 규칙과 대조한다. 파일은 수정하지 않는다.
3. 위반 항목마다 `항목 / 현재 값 / 위반 이유` 형식으로 한 줄씩 보고한다.
   위반 이유는 참고 규칙의 문구를 사용한다. 머리말, 표, code fence, 부연 설명은 붙이지 않는다.
   위반이 없으면 `위반 없음`만 출력한다.
