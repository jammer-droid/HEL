# Delivery release 10

These examples describe release 10, not the current source defaults.

| Scenario | Setting | Example |
| --- | --- | --- |
| Webhook | RETRY_LIMIT | 20 |
| Email | RETRY_LIMIT | 30 |
| SMS | RETRY_LIMIT | 40 |
| Push | RETRY_LIMIT | 50 |
| Replication | RETRY_LIMIT | 60 |

Applications could override RETRY_LIMIT for their deployment.
Retry exhaustion is reported after RETRY_LIMIT attempts.
