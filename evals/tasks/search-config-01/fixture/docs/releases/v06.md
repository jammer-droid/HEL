# Delivery release 6

These examples describe release 6, not the current source defaults.

| Scenario | Setting | Example |
| --- | --- | --- |
| Webhook | RETRY_LIMIT | 16 |
| Email | RETRY_LIMIT | 26 |
| SMS | RETRY_LIMIT | 36 |
| Push | RETRY_LIMIT | 46 |
| Replication | RETRY_LIMIT | 56 |

Applications could override RETRY_LIMIT for their deployment.
Retry exhaustion is reported after RETRY_LIMIT attempts.
