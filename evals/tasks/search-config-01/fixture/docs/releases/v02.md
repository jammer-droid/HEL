# Delivery release 2

These examples describe release 2, not the current source defaults.

| Scenario | Setting | Example |
| --- | --- | --- |
| Webhook | RETRY_LIMIT | 12 |
| Email | RETRY_LIMIT | 22 |
| SMS | RETRY_LIMIT | 32 |
| Push | RETRY_LIMIT | 42 |
| Replication | RETRY_LIMIT | 52 |

Applications could override RETRY_LIMIT for their deployment.
Retry exhaustion is reported after RETRY_LIMIT attempts.
