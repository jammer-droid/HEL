These examples describe release 12, not the current source defaults.

| Scenario | Setting | Example |
| --- | --- | --- |
| Webhook | RETRY_LIMIT | 22 |
| Email | RETRY_LIMIT | 32 |
| SMS | RETRY_LIMIT | 42 |
| Push | RETRY_LIMIT | 52 |

Applications could override RETRY_LIMIT for their deployment.
Retry exhaustion is reported after RETRY_LIMIT attempts.
