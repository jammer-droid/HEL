# Delivery release 4

These examples describe release 4, not the current source defaults.

| Scenario | Setting | Example |
| --- | --- | --- |
| Webhook | RETRY_LIMIT | 14 |
| Email | RETRY_LIMIT | 24 |
| SMS | RETRY_LIMIT | 34 |
| Push | RETRY_LIMIT | 44 |
| Replication | RETRY_LIMIT | 54 |

Applications could override RETRY_LIMIT for their deployment.
Retry exhaustion is reported after RETRY_LIMIT attempts.
