# Delivery release 15

These examples describe release 15, not the current source defaults.

| Scenario | Setting | Example |
| --- | --- | --- |
| Webhook | RETRY_LIMIT | 25 |
| Email | RETRY_LIMIT | 35 |
| SMS | RETRY_LIMIT | 45 |
| Push | RETRY_LIMIT | 55 |
| Replication | RETRY_LIMIT | 65 |

Applications could override RETRY_LIMIT for their deployment.
Retry exhaustion is reported after RETRY_LIMIT attempts.
